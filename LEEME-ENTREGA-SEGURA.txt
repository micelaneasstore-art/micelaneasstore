MICELANEASSTORE - ENTREGA SEGURA V1

ESTA VERSIÓN YA HACE:
---------------------
1. La distribución exacta de tablas forma parte del pedido firmado.
   Ya no se paga solamente "10 tablas": también quedan firmados los tipos
   (sin dobles, seguidas, diagonales, esquinas) y sus cantidades.

2. Después del pago, /api/crear-token-descarga:
   - consulta el payment_id directamente en Mercado Pago;
   - valida status=approved;
   - valida MXN;
   - valida el importe;
   - valida la referencia HMAC;
   - emite un token de descarga de 15 minutos.

3. pago-exitoso.html ya muestra el Paso 5 "Tus archivos".

4. La guía PDF puede descargarse mediante:
   /api/descargar-guia?token=...

5. Las descargas no se habilitan por manipular la URL.

IMPORTANTE - POR QUÉ TABLAS Y MAZO TODAVÍA DICEN "PREPARANDO"
-------------------------------------------------------------
El ZIP del proyecto que recibí NO contiene las carpetas de imágenes originales
limpias (img/tradicional, img/animada, img/gorditos).

Eso en realidad es bueno para seguridad: los originales no deberían estar
públicamente en Vercel.

Para generar el PDF comprado necesitamos el siguiente paso:
- subir las imágenes originales limpias a almacenamiento PRIVADO;
- el backend las lee desde ahí después de validar el pago;
- generar el PDF;
- entregar el archivo con el token temporal.

NO recomiendo volver a poner los originales limpios dentro de /img del sitio.

ACTUALIZACIÓN V2 - WEBHOOK DE DIAGNÓSTICO
------------------------------------------
Se corrigió api/webhook-mercadopago.js:

1. Ya NO responde 200 antes de consultar a Mercado Pago.
   Esto era importante en Vercel: al cerrar la respuesta primero,
   la función serverless podía terminar antes del fetch.

2. Distingue:
   - payment
   - merchant_order

3. Si recibe merchant_order:
   - consulta /merchant_orders/{id}
   - muestra status/order_status/paid_amount
   - obtiene los payment IDs asociados
   - consulta /v1/payments/{payment_id}

4. Registra:
   - status
   - status_detail
   - medio de pago
   - live_mode
   - collector_id
   - importe
   - referencia externa
   - validación de la referencia firmada

5. Si Mercado Pago falla temporalmente, devuelve HTTP 500 para permitir reintentos.

SIGUIENTE PRUEBA
